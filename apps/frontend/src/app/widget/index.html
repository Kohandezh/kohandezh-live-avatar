Assistant widget demo

This page stands in for a customer website. It is not part of any app target and it is only used to develop and check the widget. The widget itself is the floating button in the corner.

On this page the widget talks to the mock API with the embed key mock-embed-key. A real site uses its own key and the address of the backend.

Embed snippet

<script
  src="https://cdn.example.com/assistant-widget.js"
  data-api-base="https://api.example.com"
  data-embed-key="YOUR_EMBED_KEY"
  data-lang="fa"
  data-mode="voice"
  data-position="end"
  defer
></script>

The script also defines window.KohandezhAssistant, so a page can call init() itself and keep the returned open(), close() and destroy().

End of the page.
